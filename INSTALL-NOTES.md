# Installation Notes

1. Copy `energetic-materials.html` into the repository root.
2. Copy the `docs/` folder into the repository.
3. Commit the new files.
4. Push to the branch used by GitHub Pages.
5. Confirm the page at:

https://asulabs.uk/energetic-materials.html

The page intentionally uses the existing site's CSS and favicon. If the current repository changes its CSS structure later, review the page visually.

Recommended commit message:

`Add energetic materials research safety scope`
