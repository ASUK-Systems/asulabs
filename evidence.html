Evidence preservation

For important private material, preserve the original file, maintain version history and—where useful—create a cryptographic hash. Git history can support chronology when repository control is reliable. Public pages are useful publication evidence but should not be treated as conclusive proof of ownership by themselves.

Patent / confidentiality warning: A public disclosure can affect some forms of IP protection. Potentially patentable or design-sensitive material should be reviewed before publication.
